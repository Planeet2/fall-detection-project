# Emergency Contacts / 紧急联系人

## Family Contact

Name: Family member / caregiver  
Channel: mock SMS / WeChat API  
Priority: 1  

## Community Contact

Name: Community staff  
Channel: phone / service system  
Priority: 2  

## Emergency Service

Name: Emergency medical service  
Channel: emergency call  
Priority: 3  

## Notification Rule

For high-risk fall events:
1. First ask the elder for confirmation.
2. If no response, notify family contact.
3. If still no confirmation, notify community staff or emergency service.
